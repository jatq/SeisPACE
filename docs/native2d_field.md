## Controlled scoring reference

A field section does not contain a noiseless ground truth. The benchmark
therefore uses the normalized native field block as the reference and injects
real STEAD ambient-noise traces at prescribed levels. It measures how well a
method removes added noise while preserving the native field waveform.

It must not be described as supervised field-noise removal with a clean
ground-truth recording.

## Splits

The field section is split along time, not random patches:

```text
train: first 60% of time samples
validation: next 10%
test: final 30%
```

Test blocks use all channel ranges but never overlap the train or validation
time intervals. The patch size is `256 x 128`.

Each patch is clipped at its `0.5` and `99.5` percentiles and standardized once
over the complete two-dimensional block. Degenerate near-constant blocks are
resampled. This avoids row-wise normalization amplifying blank time slices.

## Data cache

Default local cache:

```text
$SEISPACE_DATA_ROOT/native_forge2d
```

Contents:

- 2000 training patches with random SNR in `[-10, 10] dB`.
- 200 validation patches at `0 dB`.
- 200 test patches at each of `-10`, `0`, and `10 dB`.
- Frozen dual-sparse prior (2D) predictions generated by the field-specific prior.

## Training protocol

The field experiment follows the same SeisPACE sequence:

1. SCRN baseline on native field patches.
2. 80-epoch prior-free paired consolidation.
3. zero-prior-channel late injection.
4. 20-epoch anchor fine-tuning against the consolidated field baseline.

The prior generator is also retrained on the native field training split. A
zero-shot synthetic-wavelet prior was evaluated first; its output collapsed the
field amplitude and correlation, so the field benchmark uses a field-specific
prior to keep the comparison scientifically valid.
